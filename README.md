# 📚 Flashcard App (Static Deck)

## 📌 Project Description
The Flashcard App is a simple, interactive web application that helps users learn and revise concepts using question-and-answer cards. Users can flip cards to reveal answers and navigate through a fixed deck using Previous and Next buttons.

## 🎯 Objective
To practice CSS 3D transforms, JavaScript arrays, DOM manipulation, state tracking, and event handling.

## 🛠️ Technologies Used
- **HTML5** – Structures the application.
- **CSS3** – Provides styling, responsive design, and 3D flip animations.
- **JavaScript** – Manages flashcards, navigation, and progress updates.

## ✨ Features
- 10 predefined question-and-answer flashcards.
- Interactive 3D card-flipping animation.
- Previous and Next navigation buttons.
- Flip Card button to reveal answers.
- Progress bar showing the current card position.
- Automatic return to the question side when changing cards.
- Disabled navigation buttons at the beginning and end of the deck.
- Responsive design for desktop and mobile devices.
- No external APIs or database required.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click a flashcard or the **Flip Card** button to reveal the answer.
5. Use the **Previous** and **Next** buttons to navigate through the cards.

No additional installation is required.
